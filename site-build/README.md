# KEIK · keik.it (anteprima statica)

Sito statico di KEIK – all day kitchen, Via Canalino 51, Modena.

- Ogni pagina è un file `.html` nella cartella principale (`index.html` è la home).
- Immagini in `assets/img/`, script in `assets/js/` (`keik-dc.js` + `morphdom`).
- Funziona su qualsiasi hosting statico (GitHub Pages, FastComet): basta caricare tutti i file.
- `404.html` è la pagina "volo non trovato".
